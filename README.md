# AmaWallet omdeni

AmaWallet omdeni is a family wallet dashboard for managing shared funds, allowances, and protected activity. Amounts throughout the app are displayed in South African rand (ZAR).

The standalone interface includes dashboards for Zithobile, Angel, and Granny, with simulated requests, transaction history, and tap-to-pay interactions.

## Project files

- `index.html` - Dashboard markup and shared app layout.
- `style.css` - Custom styling and animations.
- `script.js` - Dashboard interactions and simulated transaction updates.
- `package.json` - Project scripts and dependencies.
- `src/lib/xrplClient.ts` - XRPL client utility.
